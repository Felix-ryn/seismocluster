Port Mapping (Host → Container)

localhost:3001 → frontend nginx :80 — React SPA
localhost:8000 → backend uvicorn :8000 — FastAPI REST
localhost:5000 → mlflow UI :5000 — Experiment Tracker
localhost:5433 → db postgres :5432 — PostgreSQL

Volume Mounts

postgres_data → /var/lib/postgresql/data — persistent DB storage
./database/init.sql → /docker-entrypoint-initdb.d/ — schema init (read-only)
./backend/mlflow.db → /mlflow/mlflow.db — SQLite experiment log
./backend/mlartifacts → /mlflow/artifacts — model registry files

Env Variables Backend (Internal DNS)

DB_HOST=db — Docker DNS → container seismocluster_db
DB_PORT=5432 — port internal (bukan 5433 host)
MLFLOW_TRACKING_URI=http://mlflow:5000
MLFLOW_CLUSTERING_MODEL_NAME = SeismoCluster_Clustering_Model_KMeans
MLFLOW_ANOMALY_MODEL_NAME = SeismoCluster_Anomaly_Model_ISF

Frontend Build Pipeline (Multi-stage)

Stage 1 — node:22-alpine: npm ci + npm run build → /app/dist
Stage 2 — nginx:alpine: copy /app/dist → /usr/share/nginx/html
nginx.conf: location /api/ proxy_pass → Railway production URL
try_files $uri /index.html — SPA fallback routing

Sumber: docker-compose.yml · backend/Dockerfile · frontend/Dockerfile · frontend/nginx.conf
Network internal: container saling berkomunikasi via nama service (db, mlflow, backend) tanpa port host
